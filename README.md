# AI4Science 科学智能创新创业研学空间

响应式静态网站，依据用户提供的《20261024AI4Science科学智能创新创业研学空间.pdf》制作。图片提取自该材料；未将原始 PDF 上传到仓库。

## 本地预览

运行 `python3 -m http.server 8000` 后访问 http://localhost:8000 。无需构建和依赖安装。

## 内容维护

- `index.html`：页面内容。团队和成果数字为 2026-10-24 材料快照。
- `style.css`：响应式样式。
- `script.js`：移动端导航。
- `assets/`：原材料图示。

现有基础、新增研究方向和建设目标分别表述。未虚构团队成员姓名、联系方式、论文题目或报名渠道。图片及原材料权利归相应权利人所有。

GitHub Pages 由 main 分支根目录发布。
