PROJECT 01 / GENOMICS

AI in Genomics

Connecting genomic data, biological interpretation and experimental questions.

Our genomics project is organized around three complementary roles for AI: predicting biological properties from existing data, helping researchers analyze information, and supporting collaborative scientific reasoning.

The aim is to turn complex genomic evidence into clear, testable research questions. Each task begins with a defined endpoint and appropriate data, and progresses through analysis, evaluation and researcher review.

The framework below describes research directions and proposed workflows. It does not represent completed validation or clinical deployment.

Predict

Explore unknown biology using existing data.

Evaluation MetricsExplore endpoints, measures and interpretation

Evaluation criteria to select for each task. No project performance values are reported here. Use independent test data, appropriate units, uncertainty intervals and baseline comparisons.

Classification performanceAUROC · Average precision · Precision · Recall · F1 · MCC+

For labeled variant, splice or annotation tasks. AUROC summarizes ranking over false-positive and true-positive rates; average precision summarizes the precision–recall curve in a different way. Report the positive class, prevalence and decision threshold. F1 combines precision and recall; MCC uses all four confusion-matrix counts.

Continuous predictionMAE · RMSE · R²+

For quantitative outcomes with a defined ground truth. MAE and RMSE use the outcome’s units and are lower when errors are smaller. R² compares squared error with a constant-mean baseline and may be negative on held-out data.

Probability calibrationBrier score · Calibration curve+

For predicted probabilities with observed outcomes. Compare predicted risks with observed frequencies; use Brier score alongside a calibration plot and discrimination metrics. Report independent-population performance when applicable.

Candidate prioritizationPrecision@k · Recall@k · Independent confirmation+

For ranked gene, variant or target lists. Define k and a reference set before scoring. Precision@k is the fraction of top-k candidates labeled positive; recall@k is the fraction of all reference positives recovered. Reference labels may be incomplete.

Structure assessmentpLDDT · PAE · Comparison to a reference structure+

For protein-structure hypotheses. pLDDT reports local confidence and PAE concerns relative positional uncertainty. Neither is an affinity measure. If a suitable experimental reference exists, evaluate structural agreement separately.

Evidence and workflow qualitySource support · Reproducibility · Runtime · Failure rate+

For literature synthesis, annotation and automated workflows. Define an audited set to assess whether extracted claims are supported. Record software, inputs, versions and parameters; measure runtime and failure rates under stated conditions.

Research outputs

Depending on the task, outputs may include a curated dataset, reproducible analysis, evidence-linked annotations, a prioritized candidate set, or an experimental plan. Reports should distinguish observations, predictions and proposed interpretations.
